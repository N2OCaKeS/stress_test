# Система автоматического создания/востановления снимков clonezilla и настройки стендов нагрузочного тестирования далее ACS
### ACS основана по принципам RESTAPI и реализована с помощью фреймфорка FastAPI, для дальнейшей интеграции с веб-приложениями, телеграм-ботами и т.п.

## Запуск
Запуск системы в данный момент происходит двумя способами:

Способ №1 (рекомендованный)

1. Установить docker и docker-compose
```
sudo apt install docker.io
sudo apt install docker-compose
```
Если нет в репозитории то воспользоваться инструкцией https://docs.docker.com/compose/install/linux/

2. Находясь в директории ACS cобрать образы
```
sudo docker-compose build
```
3. Находясь в директории ACS запустить контейнер с postgres:15 и приложением.  По умолчанию работает на порту 9999
```
sudo docker-compose up -d
```

Способ №2
1. Для начала необходимо создать виртуальное окружение

```
python3 -m venv venv
```
2. Активировать виртуальное окружение
```
source venv/bin/activate
```
3. Необходимо установить необходимые для работы библиотеки
```
pip3 install -r requirements.txt
```
4. Установить СУБД postgresl
```
sudo apt install postgresql
```
5. Заполнить аутентификационные данные для СУБД в файле .env
6. Выполнить необходимые миграции
```
alembic update head
```
7. Находясь в директории ACS запустить саму систему. По умолчанию работает на порту 8000, при необходимости можно изменить параметром --port <номер_порта>
```
uvicorn src.main:app --host 0.0.0.0 --reload --port 8000
```
В ближайшем будущем будет добавлена возможность запуска из docker образа

## Описание API
У данной системы присутсвует интерактивная документация по пути /docs

ACS на данный момент имеет 3 основных блока:
1. Блок для настройки стенда
2. Блок для взаимодействием с clonezilla
3. Блок для работы с локальной СУБД, в которой хранятся необходимые данные для работы. На данный момент реализована работа с СУБД Postgresql

Блок для настройки стенда включает в себя функционал:
 - Изменения репозитория
 - Установка необходимых пакетов
 - Клонирование git репозитория
 - Скачивание qa-init
 - Настройка alias
 - Настройка сетевого соединения
 - Установка необходимых ядер для определенной версии
 - Обновление ОС Astra Linux
 - Выполнить все вышеперечисленные настройки, за исключением обновления ОС Astra Linux одним запросом

 Блок для взаимодействия с clonezilla включает в себя функционал:
 - Просмотр имеющихся снимков
 - Создание снимка
 - Восстановление снимка

 Блок для работы с локальной СУБД включает в себя функционал:
 - Получить информацию о стенде
 - Добавить новый стенд
 - Получить информацию о доступных версиях ОС Astra Linux в ACS
 - Добавить версию ОС Astra Linux
 - Получить информацию о репозитории привязанной к конкретной версии ОС AL
 - Добавить репозиторий привязанный к конкретной версии ОС AL (Для добавления более чем 1 репозиторий, необходимо записать их просто через \n)
