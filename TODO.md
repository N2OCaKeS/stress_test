#

Привет у меня есть cli утилита мне надо в нее добавить 2 команды которым нужен будет логин
allta jira service
allta jira testcase

Данные команды будут по заданному шаблону создавать задачи в jira и спрашивать необходимую информацию в интерактивном режиме с возможностью как выбора так и интерактивного ввода

Креды для jira брать как команда allta token и брать следующие креды: username и jira_token.

Будут 2 схемы создания задач

1. service
   Cоздает 4 задачи, спрашивает номер спринта, далее создает задачи с именами:
   1) "Спринт_<номер спринта>. Daily" storypoint = 2,
   2) "Спринт_<номер спринта-1>. Review" storypoint = 1,
   3) "Спринт_<номер спринта+1> Планирование" storypoint = 3,
   4) "Спринт_<номер спринта+1> Ретроспектива" storypoint = 1
    исполнителем устанавливает пользователя из креды username, добавляет компонент к каждой задаче компонент "НТ. Sprint backlog" и каждой задаче добавлет storypoint оценку к каждой задаче своё количество storypoint
2. testcase
   Создает 9 задач, запрашивает: код эпика чтобы привязать задачу к эпику(например DEVQA-5454, DEVQA-8556, желательно сразу указать по умолчанию префикс DEVQA- и чтобы пользователь сразу передавал только цифры), название задачи(интерактивный ввод), название компонента (интерактивный ввод путем выбора из 2 возможных компонентов на каждую задачу НТ. Sprint backlog или НТ. main Backlog выбор цифрами 1 или 2), исполнитель (выбор цифрой на каждую задачу или на все задачи 1-3 mfilippenko, dtimonin, ivelikanov). Так же у некоторых задач будет указано кол-во storypoint по умолчанию.
   Списко задач:
   1) "НТ. <Имя задачи>. Подготовка окружения."
   2) "НТ. <Имя задачи>. Нагрузочный скрипт."
   3) "НТ. <Имя задачи>. Обработка результатов."
   4) "НТ. <Имя задачи>. Выкладка результатов на Life." storypoint=2
   5) "НТ. <Имя задачи>. Написать README + выложить описание на Life." storypoint=2
   6) "НТ. <Имя задачи>. Добавить тесткейс в BT" storypoint=0.5
   7) "НТ. <Имя задачи>. Добавить в статистику"
   8) "НТ. <Имя задачи>. Добавить в allta" storypoint=2
   9) "НТ. <Имя задачи>. Итоговое тестирование." storypoint=2

Так же будет необходимо выделить в каталог с конфигами чтобы можно было легко и просто поменять url для jira по умолчанию используем: https://jira.astralinux.ru/
