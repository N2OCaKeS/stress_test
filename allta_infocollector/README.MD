# ALLTA InfoCollector        
Проект является микросервисом, расширяющим возможности веб-приложения **ALLTA**.   
Доступен по адресу: [http://allta.devos.astralinux.ru](http://allta.devos.astralinux.ru)   
     
Представляет собой сервис мониторинга нагрузки и основных метрик пула серверов.    
Реализован на связке docker контейнеров *Node exporter -> Prometheus -> Grafana*    

### Как установить
- Склонировать репозиторий    
- Перед первым запуском отредактировать файл *infocollector.conf* согласно своему окружению    
- Запустить скрипт *config_handler.py*     
- Запустить скрипт *install.sh*    

### Как обновить
Если сервис уже установлен и необходимо обновить конфигурацию:    
- Выполнить первые 3 пункта из предыдущего абзаца    
- Перезапустить сервис **systemctl restart allta_infocollector.service**
