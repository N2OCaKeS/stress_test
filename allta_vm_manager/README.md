# Allta_v3

## Описание

Программный комплекс Allta предназначен для упрощения работы отдела нагрузочного тестирования ДБОС (далее team13)

ПК Allta это проект микросервисной архитекруты и состоит из различных частей как из самописных сервисов разрабротанных team13, так и сервисов с открытым исходным кодом которые были развернуты в целях оптимизации рабочих процессов. Для оптимизации развертывания проект был упакован в docker контейнеры, а они в свою очеред обернуты в docker-compose, что в свою очеред существенно упрощает настройку и развертывание всех сервисов. В будущем планируется перенести архитектуру с docker-compose на kubernetes или docker-swarm в целях удобства управления

Проект доступен по адресу: [allta](http://allta.devos.astralinux.ru)

### Состав ПК Allta

Allta из нескольких частей, а именно:

#### Самописная

Самописная часть состоит из таких сервисов как:

| Имя сервиса         | Тип сервиса | Описание                                                                           |
| ------------------- | ----------- | ---------------------------------------------------------------------------------- |
| allta_web           | frontend    | веб приложение для удобного взаимодействия с сервисами                             |
| allta_auth_api      | backend_api | api для централизованного входа в систему                                          |
| allta_vm_api        | backend_api | api для управления виртуальными машинами развернутыми на 1 или нескольких серверах |
| allta_config_api    | backend_api | api для получения конфигурационных файлов для стресс тестов                        |
| allta_statistic_api | backend_api | api для хранения и обработки статистики по пройденным тестам                       |
| allta_bot           | service     | телеграмм бот                                                                      |

#### Opensource решения

Из сервисов с открытым кодом наша команда использует следующие сервисы:

| Имя сервиса | Тип сервиса | Описание                                                                                       |
| ----------- | ----------- | ---------------------------------------------------------------------------------------------- |
| devpi       | service     | сервис для хранения и использования модулей python собственной разработки. Частный аналог pypi |
| grafana     | service     | сервис для отслеживания нагрузки на сервера                                                    |
| nginx       | service     | сервис используется как единая точка входа для всех сервисов                                   |

## Установка

### Развертывание проекта

Существует 2 способа развертывания

1. Установка с помощью скрипта (рекомендуется) - разворачивает всю архитектуру, так же создает `unit` файлы для `systemctl` для точечного обновления сервисов, а не массового отключения на время обновления.
2. Установка вручною - можно детально настроить каждый отдельный сервис и выборочно выполнить запуск сервисов

#### 1. Установка с помощью скрипта

1. Настройка окружения (Опционально)

Необходимо перейти в каталог `docker_allta/env` и скопировать файлы из `docker_allta/env/example`, а также необходимо убрать часть имени `example.` у каждого файла и настроить их содержимое

```bash
cd docker_allta/env

cp example/* .
for f in example.*; do  mv -- "$f" "${f#example.}" done

```

Установит сразу все зависимости и поднимит программный комплекс. так же добавить systemctl юниты для упрощения поднятия или обновления конкретных сервисов

```bash
sudo ./install.sh
```

#### 2. Установка вручную

##### Зависимости

```bash
sudo apt install docker.io docker-compose
```

##### Развертывание сервиса

```bash
cd docker_allta 
docker-compose up -d --build
```
