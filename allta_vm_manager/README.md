# Allta_app_services

## Описание проекта

Allta_app_services это программный комплекс состоящий из множества компонентов и необходим для управления серверами и виртуальными машинами на них развернутыми. Так же проект в себя включает api для авторизации и api для удобного получения конфигурационных файлов и токенов. Все api являются защищенными и пользователь не прошедший авторизацию не сможет использовать ни одно из них.

## Установка проекта

###

#### 1. Подготовка к установке

1. Необходимо склонировать git репозиторий в отдельный каталог и переключиться на ветку с проектов

    ```bash
    mkdir allta_app_service
    git clone ssh://git@git.astralinux.ru:7999/qa/stress_test.git
    git checkout allta-vmmanager
    ```

2. Необходимо запустить скрипт установки зависимостей и генерации конфигураций

    ```bash
    sudo ./install.sh precond
    ```

#### 2. Конфигурирование сервисов

1. Необходимо перейти и настроить все креды для сервисов

    1. Перейти в каталог с кредами и просмотреть их список

        ```bash
        cd /var/allta_services/config
        ls -a
        ```

    2. По очередно начать изменять креды(все подсказки будут внутри кред, в местах где необходимо установить значения выделены в формате <ПОЛЬЗОВАТЕЛЬ> <ПАРОЛЬ>)

        Рекомендуемая последовательность при настройке:

        1. Базы данных
        2. Redis
        3. Redis comander
        4. celery
        5. flower
        6. api (для каждого api необходимо указывать пользователя и пароль от соответственной БД)

        ```bash
        nano env.allta_<имя сервиса>
        ```

#### 3. Запуск сервисов

1. Запускаем сервисы

   ```bash
   install.sh start
   ```

## Обновление проекта

###

#### 1. Остновка сервисов

   ```bash
   install.sh stop
   ```

#### 2. Обновляем git

   ```bash
   git pull
   ```

#### 3. Запускаем сервисы

   ```bash
   install.sh start
   ```

#### Открытые порты

Иные порты кроме как открых закрыты и доступ к сервисам осуществляется только через внутренние сети docker. Многие контейнеры разделены на различные сети для исключения конфликтов.

| Порт  |  Сервис   | Для чего нужен                                                           |
| :---: | :-------: | ------------------------------------------------------------------------ |
|  80   |   nginx   | Необходим как единая точка входа во все сервисы                          |
| 9443  | portainer | Необходим для доступа к portainer (проксирование через nginx невозможно) |

1. Сборка cli утилит

    Необходимо собирать на версии ОС astra 1.7.5.9. Это необходимо для максимальной совместимости собранного пакета.

    ```bash
    cd cli
    ./build.sh <имя каталога с нужным сервисом>
    ```

    Готовый файл сохраняется в директории запуска:

    ```bash
    ls *.deb
    ```

    Пример:

    ```bash
    ./build.sh allta_vm
    ```

2. После сборки утилиты ее необходимо разместить на ftp сервере по пути

    [ftp://10.177.103.10/boxes/allta-vm_1.0.0_amd64.deb](ftp://10.177.103.10/boxes/allta-vm_1.0.0_amd64.deb)
