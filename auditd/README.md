# Нагрузочное тестирование.
## Auditd_benchmark
Система нагрузочного тестирования демона аудита (auditd).

### **Настройка тестовой машины**
Для настройки стендовой машины перед проведение тестирования необходимо:
1. Cклонировать сей проект.

`git clone -b auditd ssh://git@git.astralinux.ru:7999/qa/stress_test.git`

2. Далее необходимо вписать путь до проекта в переменную **SCRIPT_DIR** в файле **aub_conf.py**. 
   
`SCRIPT_DIR = '/media/sf_git/stress_test/auditd_benchmark'`

3. Далее необходимо создать виртуальное окружение.

`cd auditd_benchmark && ./aub_prep.sh`

### **Запуск**
На данный момент реализовано **3** набора тестов.

- **psaud** - нагрузка при помощи событий аудита системных процессов.
- **useraud** - нагрузка при помощи событий аудита локальных пользователей.
- **fileaud** - нагрузка при помощи событий аудита файлов и директорий.

И **3** режима тестирования.

- **default** - режим используется по умолчанию. Выполняется итеративный проход по всем событиям с итеративным же увеличением количества процессов-генераторов для каждого события, 
с предварительной очисткой файлов отчета и составлением итогового отчета

- **extended** - выполняется проход конкретному событию (указывается с помощью доп. аргумента _--event_) с итеративным увеличением количества процессов-генераторов, 
с предварительной очисткой файлов отчета и без составлением итогового отчета

- **test** - отладочный режим. Использовать при внедрении нового функционала.

Запуск теста производить от суперпользователя (root):

`cd auditd_benchmark`

`venv/bin/python aub_run.py`

- _**--testlist**_  - обязательный выбор набора тестов
- _**--mode**_  - необязательный выбор режима (по умолчанию _default_)
- _**--event**_ - необязательный выбор события ( при использовании _extended_)

### **Проведение тестирования**
Во время проведения тестирования в терминал выводится информация о текущем тесте.
### **Обработка результатов**
После прохождения теста в текущей папке auditd_benchmark/report создается .tar с результатами тестирования в виде графиков и таблиц.
