# Auditd_benchmark
Система нагрузочного тестирования демона аудита (auditd). 


### Test 1
### Auditd_psaud
Создается нагрузка посредством генерации событий аудита системных процессов.   
Выполняется итеративный проход по всем событиям с итеративным же увеличением количества    
процессов-генераторов для каждого события.    
Выполняется в режиме **смоленск**.   


### Test 2
### Auditd_useraud
Создается нагрузка посредством генерации событий аудита локальных пользователей.   
Выполняется итеративный проход по всем событиям с итеративным же увеличением количества    
процессов-генераторов для каждого события.    
Выполняется в режиме **смоленск**. 


### Test 3
### Auditd_fileaud
Создается нагрузка посредством генерации событий аудита файлов и директорий.   
Выполняется итеративный проход по всем событиям с итеративным же увеличением количества    
процессов-генераторов для каждого события.    
Выполняется в режиме **смоленск**.

#### Проведение тестирования
Тестирование проводится в автоматическом режиме с помощью оркестратора Bendiks.

- [Bendiks](https://life.astralinux.ru/pages/viewpage.action?pageId=253888776&src=contextnavpagetreemode)

#### Обработка результатов
Результаты обрабатываются и выкладываются в пространстве нагрузочного тестирования confluence 
с помощью орекстратора Bendiks в автоматическом режиме.
