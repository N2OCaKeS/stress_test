Описание

Система нагрузочного тестирования демона аудита (auditd). Специальным образом в системе строятся процессы-генераторы событий аудита. Каждый процесс с заданной периодичностью выдает события, которые в свою очередь должен отлавливать auditd. Выполняется итеративный проход по всем событиям с итеративным же увеличением количества процессов-генераторов для каждого события. Далее все необходимые зависимости будут представлены в графическом виде.
