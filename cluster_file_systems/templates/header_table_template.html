Описание

Система нагрузочного тестирования кластерных ФС с использованием функционала fs_mark-3.3. Программа fs_mark предназначена для низкоуровневой обработки файлов. Метод синхронизации: INBAND FSYNC fsync() для каждого файла в цикле записи. Подкаталоги не используются. Длина имени файлов 40 байт (16 начальных байтов метки времени с 24 случайными байтами в конце имени) Результатом тестирования является таблица значений со следующими параметрами:

  • fs_use: насколько заполнена файловая система в первом указанном каталоге в процентах;
  • file_count: сколько файлов было записано на данный момент;
  • file_size: размер записываемых файлов в байтах;
  • speed: скорость записи файлов на диск в микросекундах;
  • app_overhead: это время в микросекундах, затраченное на выполнение теста без выполнения системных вызовов, связанных с записью файла;
  • create_min: минимальное время, потраченное на системные вызов 'create';
  • create_avg: среднее время, потраченное на системные вызов 'create';
  • create_max: максимальное время, потраченное на системные вызов 'create';
  • write_min: минимальное время, потраченное на системные вызов 'write';
  • write_avg: среднее время, потраченное на системные вызов 'write';
  • write_max: максимальное время, потраченное на системные вызов 'write';
  • fsync_min: минимальное время, потраченное на системные вызов 'fsync';
  • fsync_avg: среднее время, потраченное на системные вызов 'fsync';
  • fsync_max: максимальное время, потраченное на системные вызов 'fsync';
  • sync_min: минимальное время, потраченное на системные вызов 'sync';
  • sync_avg: среднее время, потраченное на системные вызов 'sync';
  • sync_max: максимальное время, потраченное на системные вызов 'sync';
  • close_min: минимальное время, потраченное на системные вызов 'close';
  • close_avg: среднее время, потраченное на системные вызов 'close';
  • close_max: максимальное время, потраченное на системные вызов 'close';
  • unlink_min: минимальное время, потраченное на системные вызов 'unlink';
  • unlink_avg: среднее время, потраченное на системные вызов 'unlink';
  • unlink_max: максимальное время, потраченное на системные вызов 'unlink';
Далее все необходимые зависимости будут представлены в графическом виде.
