Заглушки для read-only volume'ов DRBL из docker-compose.yml.

На ноутбуке/CI реального DRBL нет — эти пустые каталоги подставляются по
умолчанию, чтобы `docker compose up` вообще поднимался без хоста 10.177.103.10.

На реальном деплое (103.10) переопределить через .env или переменные
окружения перед `docker compose up`:

    DRBL_USR_SBIN=/usr/sbin
    DRBL_SHARE=/usr/share/drbl
    DRBL_ETC=/etc/drbl

Точные пути сверить по `dpkg -L drbl` — состав пакета под конкретный
дистрибутив может отличаться от предположенного в плане контейнеризации.
