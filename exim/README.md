# Нагрузочное тестирование почтовых сервисов (exim4, dovecot)

## Описание
1. SMTP Test - тестирование отправки электронной почты через SMTP
2. IMAP Test - тестирование чтения электронной почты через IMAP

## Конфигурация

Перед запуском необходимо настроить параметры в файле `exb_conf.py`

```
# Параметры SMTP теста
MAIL_START = 20           # Начальное количество писем
MAIL_MAX = 100            # Максимальное количество писем
MAIL_STEP = 20            # Шаг увеличения количества писем

# Параметры IMAP теста
MAIL_USERS_QTY_START = 20  # Начальное количество пользователей
MAIL_USERS_QTY_MAX = 100   # Максимальное количество пользователей
MAIL_USERS_QTY_STEP = 20   # Шаг увеличения количества пользователей
```

## Использование
1. SMTP Test - Тестирует производительность отправки писем через SMTP сервер (exim4-daemon-heavy)
Что делает тест:
- Отправляет письма с увеличением нагрузки от `MAIL_START` до `MAIL_MAX` с шагом `MAIL_STEP`
- Использует пул потоков для параллельной отправки
- Замеряет метрики: количество успешно отправленных, количество успешно отправленных/сек

2. IMAP Test - Тестирует производительность чтения писем через IMAP сервер (dovecot-imapd).
Что делает тест:
- Подготовительная фаза: отправляет по `N_PREP_MAIL` писем каждому пользователю
- Фаза тестирования: параллельное чтение с увеличением нагрузки от `MAIL_USERS_QTY_START` до `MAIL_USERS_QTY_MAX` с шагом `MAIL_USERS_QTY_STEP`писеми всеми пользователями
- Фаза очистки: удаление всех тестовых писем

## Результаты тестирования
Результаты фиксируется в файл указанный в `exb_conf`

После выполнения теста `SMTP`, в результатах сохраняются: 
1. Количество отправленных писем
2. Количество успешных отправок
3. Скорость отправки (успешно отправленных писем в секунду)

После выполнения теста `IMAP`, в результатах сохраняются:
1. Количество пользователей
2. Количество успешных пользователей прочитавших почту
3. Количество пользователей не прочитавших почту
4. Средняя задержка (avg_latancy)
5. Операций/сек (throughput)

## Особенности реализации

1. Параллельное выполнение: Используется ThreadPoolExecutor для одновременной отправки/чтения писем
2. Постепенное увеличение нагрузки: Тесты выполняются с увеличивающейся нагрузкой для анализа производительности
3. Обработка ошибок: Детальная классификация различных типов ошибок
4. Автоматическая очистка: IMAP тест автоматически удаляет созданные тестовые письма
