# Freeipa benchmark

### Система нагрузочного испытания контроллера домена на базе freeipa

### Test 1

### FreeIPA auth

> Для выполнения необходимо 3 хоста (КД, клиент, хост откуда запускается испытание)

На данный момент имеется сценарий нагрузочного испытания посредством множественного одновременного числа аутентификации и авторизации (сценарий с одновременным множественным вводом клиентов в домен удален из-за нехватки ресурсов, если необходим, смотрите начальные коммиты)

Тестовый сценарий включает в себя:
- Разворачивание контроллера домена
- Ввод клиента в домен
- Создание N уникальных пользователей
- Нагрузочный тест

Перед запуском необходимо определить необходимые значения в конфигурационном файле ipa_conf.py такие как:
1. ip-адрес контроллера домена (на этот хост будет развернут astra-freeipa-server)
2. ip-aдрес клиета (на этот хост будет развернут astra-freeipa-client)
3. Максимальное число процессов, выполняющих аутентификацию и авторозирацию одновременно
4. Шаг увеличиния числа процессов, выполняющих аутентификацию и авторизацию одновременно

Результаты записываются в файл ipa_report.txt и включают в себя:
- Количество уникальных пользователей
- Процент ошибок
- Средняя задержка при аутентификации и авторизации
- Время аутентификации и авторизации последнего - 5 пользователя
- Минимальное время аутентификации и авторизации
- Максимальное время аутентификации и авторизации

По полученным данным строятся графики и рассчитывается итоговый рейтинг в соответсвии с утвержденной математической моделью https://life.astralinux.ru/pages/viewpage.action?pageId=164513738 https://life.astralinux.ru/pages/viewpage.action?pageId=150939635

При рассчете рейтинга участвуют только такие критерии как:
- Процент ошибок: ранг 0.3
- Средняя задержка при аутентификации и авторизации: ранг 0.5
- Время аутентификации и авторизации последнего - 5 пользователя: ранг 0.2

Данные критерии являются негативными

Выполняется в режиме **орел**

### Test 2

### FreeIPA create-users

> Для выполнения необходимо 3 хоста (КД, клиент, хост откуда запускается испытание)

На данный момент имеется сценарий нагрузочного испытания посредством множественного добавления пользоватей

Тестовый сценарий включает в себя:
- Разворачивание контроллера домена
- Ввод клиента в домен
- Нагрузочный тест

Перед запуском необходимо определить необходимые значения в конфигурационном файле ipa_conf.py такие как:
1. ip-адрес контроллера домена (на этот хост будет развернут astra-freeipa-server)
2. ip-aдрес клиета (на этот хост будет развернут astra-freeipa-client)
3. Максимальное число потоков, выполняющих создание пользователей
4. Шаг увеличиния числа потоков, выполняющих создание пользователей

По полученным данным строятся графики и рассчитывается итоговый рейтинг в соответсвии с утвержденной математической моделью https://life.astralinux.ru/pages/viewpage.action?pageId=164513738 https://life.astralinux.ru/pages/viewpage.action?pageId=150939635

При рассчете рейтинга участвуют только такие критерии как:
- Количество успешно созданных пользователей (позитивный критерий)
- Время создания всех пользователей (негативный критерий)
- Среднее время создания пользователя (негативный критерий)

Так как данные критерии было принято обозначить как равноценные их ранг равен 0.333

Выполняется в режиме **орел**

### Test 2

### FreeIPA Plagin
> Для выполнения необходимо 3 хоста (КД, клиент, хост откуда запускается испытание)

Тестовый сценарий включает в себя:
- Разворачивание контроллера домена
- Ввод клиента в домен
- Нагрузочный тест

Нагрузочный тест:
1. Создать большого количества пользователей freeipa, последние N пользователи добавлены в группу gr_1
2. Зафиксировать время добавления пользователей из группы gr_1 в группу gr_2
3. Зафиксировать etime ldap запроса

Выполняется в режиме **Смоленск**
