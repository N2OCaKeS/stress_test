# Математическая модель

## Обозначения

- `x_{i,j}` — j‑е исходное значение метрики i.
- `n_i` — количество значений по метрике i.
- `w_i` — вес метрики i, `Σ_i w_i ≈ 1`.
- `sign_i ∈ {+1, -1}` — знак метрики (`+1` — больше лучше, `-1` — меньше лучше).
- `L_i`, `U_i` — нижняя/верхняя границы нормализации (может отсутствовать любая из них).
- `y_{i,j}` — нормализованное значение.
- `y_i` — агрегированное значение метрики i.
- `c_i` — вклад метрики i в рейтинг.
- `ε` — малая константа для защиты деления на ноль.

## 1) Нормализация (MinMax)

Для набора значений `{x_{i,j}}` каждой метрики:

1. Обрезка по границам:  
   `x̃_{i,j} = min( max( x_{i,j}, L_i ), U_i )`
2. Дополняем фиктивными точками, если заданы границы:  
   `Z_i = { x̃_{i,j} } ∪ {L_i (если есть)} ∪ {U_i (если есть)}`
3. Min–max масштабирование:
   - Диапазон `[0, 1]`:  
     `y_{i,j} = ( x̃_{i,j} - min(Z_i) ) / ( max(Z_i) - min(Z_i) )`
   - Диапазон `[-1, 1]`:  
     `y_{i,j} = 2 * ( ( x̃_{i,j} - min(Z_i) ) / ( max(Z_i) - min(Z_i) ) ) - 1`

`MathModels.normalize` применяет это к каждому Criterion отдельно.  
`MathModels.normalize_criteria` сначала объединяет все значения, нормализует одной шкалой, затем разбивает обратно.

## 2) Аппроксимация ряда

Даны точки `(t_k, v_k)`, `k = 1..n`.

1. Степень `d = min(degree, n-1)`.
2. Пробуем `polyfit` степени `d`; при `RankWarning` уменьшаем `d` на 1 и повторяем.
3. Если `d = 0`, берём константу.

Результат — полином  
`p(t) = Σ_{m=0..d} a_m · t^{d-m}`.

## 3) Агрегация по метрике

Из (нормализованных) значений выбираем агрегат:

- mean: `y_i = (1 / n_i) · Σ_{j=1..n_i} y_{i,j}`
- last: `y_i = y_{i,n_i}`
- max/min: `y_i = max_j y_{i,j}` / `min_j y_{i,j}`

## 4) Total Rating

Формула: `R = Σ_i ( w_i · (y_i + ε) )^{s_i}`, `w_i > 0`, `s_i = 1` при `sign_i >= 0`, `s_i = -1` при `sign_i < 0`.

Вклад метрики i (значения всегда берутся после нормализации):

- Позитивная (`sign_i >= 0`): `c_i = w_i · (y_i + ε)`.
- Негативная (`sign_i < 0`): `c_i = 1 / ( w_i · (y_i + ε) )`.

Все вклады неотрицательны; `ε` защищает деление на ноль. Ненормализованные входы в Total Rating не используются. В коде используется `ε = 1e-3`.
