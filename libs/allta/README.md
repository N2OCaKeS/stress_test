# Модуль allta

## Описание

Модуль содержит в себе реализацию классов для упрощения написания stress тестов для ОС Astra Linux

## Установка

```bash
pip install -i http://10.177.103.10:3141/root/release --trust 10.177.103.10 allta
```

## Использование

###

Модуль содержить в себе несколько файлов и классов подробнее с ними и что они делают можно ознакомиться ниже

#### 1. BaseDecorators

Данный Класс содержит в себе базовые декораторы необходимых для отладки тестов. На текущий момент содержит в себе:

1. @trycorator: данный декоратор используется для вывода в случае ошибки информации в какой функции она произошла

#### 2. SystemCommands

Данный класс содержит в себе функции для работы с ОС. На текущий момент содержит в себе:

1. check_output_command()

    Данный метод используется для выполнения команды с получением полного вывода о выполнении.
    Пример использования:

    ```python
    from allta import SystemCommands

    SystemCommands.check_output_command('sudo apt-get update')
    ```

2. cmd_with_returncode()

    Данный метод используется для выполнения команды с получением кода завершения.
    Пример использования:

    ```python
    from allta import SystemCommands

    SystemCommands.cmd_with_returncode('sudo apt-get update')
    ```

3. cmd()

    Данный метод используется для выполнения команды без получения какой либо информации:

    ```python
    from allta import SystemCommands

    SystemCommands.cmd('sudo apt-get update')
    ```

#### 3. VBoxManager

Данный класс содержит в себе все для настройки и выполнения команд на виртуальных машинах под управлением провайдера Virtual Box. На текущий момент реализованы следующие методы:

1. prepare

    Используется для выполнение прекондишна в тесте

2. build

    Используется для сборки виртуальных машин
3. check

    Используется для проверки доступности виртуальных машин
4. execute

    Используется для выполнения команд на виртуальных машинах
5. scp

    Используется для обмена файлами с виртуальными машинами
6. set_hosts

    Используется для настройки хостов внутри виртуальных машин
7. sed

    Используется для упрощения работы с командой sed внутри виртуальных машин
8. freeipa

    Используется для настройки контроллера домена и клиентов домена freeipa
9. apt.(install \ remove \ reinstall)

    Используется для упрощения работы с пакетами внутри виртуальных машин
