Decorators
=================

Модуль ``Decorators`` предоставляет базовые декораторы для обработки ошибок и измерения времени выполнения. Это облегчает оборачивание функций в блоки try/except и помогает контролировать время работы.

.. note:: 
    Автор: ``dtimonin``


------------------------------------------------
``trycorator``
------------------------------------------------

Декоратор который оборачивает функцию в try/except.
При возникновении исключения печатает название функции, тип ошибки и сообщение в stdout.

""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""

* ``function``: callable - функция, которую нужно обернуть

""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""

* ``callable`` - обернутая функция, возвращает результат исходной функции
* При исключении возвращает ``None``

""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import BaseDecorators

    @BaseDecorators.trycorator
    def divide(a, b):
        return a / b

------------------------------------------------
``timer``
------------------------------------------------

Декоратор который измеряет время выполнения функции и выводит его в stdout.
Формат вывода: ``[имя_функции] Выполнялась: X часов Y минут Z секунд W миллисекунд``.

""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""

* ``function``: callable - функция, которую нужно обернуть

""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""

* ``callable`` - обернутая функция, возвращает результат исходной функции

""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import BaseDecorators

    @BaseDecorators.timer
    def heavy_work():
        total = 0
        for i in range(1_000_000):
            total += i
        return total

    heavy_work()
