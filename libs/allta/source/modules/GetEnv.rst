GetEnv
=====================

Работа с переменными окружения и путями к ним

.. note:: 
    Автор: ``amedvedev``

------------------------------------------------------------------------------------------------
``activate_absolute``
------------------------------------------------------------------------------------------------

Активировать env через абсолютный путь 

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``absolute_path``: str - абсолютный путь

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_absolute("/home/absolute/path")

``get``
------------------------------------------------------------------------------------------------

Получить переменную (после активации)

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``environment_var``: str - переменная окружения

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``str`` - значение переменной

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_relative("../relative/path")
    print(GetEnv.get("VARIABLE"))

Получить словарь всех переменных (после активации)

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict`` - словарь всех переменных ({var1: value1, var2: value2, ...})

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
