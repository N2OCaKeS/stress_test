GetEnv
=====================

Работа с переменными окружения и загрузкой .env файлов.
Поддерживаемый формат: ``KEY=VALUE``, пустые строки и строки, начинающиеся с ``#`` игнорируются.

.. note:: 
    Автор: ``amedvedev``

------------------------------------------------------------------------------------------------
``activate_absolute``
------------------------------------------------------------------------------------------------

Активировать env через абсолютный путь.
Если env уже активирован, повторный вызов ничего не делает.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``full_path``: str - абсолютный путь до файла .env

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_absolute("/home/absolute/path")

------------------------------------------------------------------------------------------------
``activate_relative``
------------------------------------------------------------------------------------------------

Активировать env через относительный путь.
Если env уже активирован, повторный вызов ничего не делает.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``relative_path``: str - относительный путь до файла .env

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_relative("../relative/path")

------------------------------------------------------------------------------------------------
``get``
------------------------------------------------------------------------------------------------

Получить переменную (после активации).
Если переменная не найдена, возбуждается ``RuntimeError``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``name``: str - имя переменной окружения

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``str`` - значение переменной

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_relative("../relative/path")
    print(GetEnv.get("VARIABLE"))

_______________________________________________________________________________________________

------------------------------------------------------------------------------------------------
``get_loaded_vars``
------------------------------------------------------------------------------------------------

Получить словарь всех переменных, загруженных из env (после активации).

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict`` - словарь переменных, загруженных из env ({var1: value1, var2: value2, ...})

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import GetEnv
    GetEnv.activate_relative("../relative/path")
    print(GetEnv.get_loaded_vars())
