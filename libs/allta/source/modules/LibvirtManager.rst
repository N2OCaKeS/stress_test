LibvirtManager
=====================

Модуль ``LibvirtManager`` содержит классы для управления ВМ под управлением Libvirt.

.. note:: 
    Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``Vm.vm_list``
------------------------------------------------------------------------------------------------

Возвращает список всех ВМ из ``virsh --connect qemu:///system list --all``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``str`` - вывод команды ``virsh list --all``

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager

    print(LibvirtManager.Vm.vm_list())

------------------------------------------------------------------------------------------------
``Vm.bridge``
------------------------------------------------------------------------------------------------

Переводит ВМ на сетевой интерфейс типа мост (``br0``).
Скрипт ``static_ip.sh`` настраивает статический IP внутри ВМ, затем выполняется перезагрузка.
Требует ``sudo`` на хосте и SSH-доступ к ВМ.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms_date``: dict - текущая информация о ВМ (после ``Libvirt.build``)
* ``new_vms_date``: dict - информация о ВМ с новыми значениями ``ip_bridge``
* ``username``: str, optional - имя пользователя для SSH (default ``u``)
* ``password``: str, optional - пароль пользователя (default ``1``)

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    vms_dates = {
        'testvm1': {
            'cpu': '4',
            'ram': '4096',
            'ip_bridge': '10.177.103.180',
        },
        'testvm2': {
            'cpu': '2',
            'ram': '2048',
            'ip_bridge': '10.177.103.181',
        },
    }
    vms = list(vms_dates.keys())

    old = Libvirt.build(box='1.7.5.o', rc='1.7.5', vms=vms, vms_dates=vms_dates)

    LibvirtManager.Vm.bridge(
        vms_date=old,
        new_vms_date=vms_dates,
        username='u',
        password='1',
    )

------------------------------------------------------------------------------------------------
``Vm.additional_disk``
------------------------------------------------------------------------------------------------

Подключает дополнительные диски к ВМ и, при необходимости, форматирует и монтирует их внутри гостя.
Поддерживаются qcow2 диски и физические устройства хоста.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms_dates``: dict - полная информация о ВМ (используется ключ ``additional_disks``)
* ``disk_path``: str, optional, default=/vms/additional_disk - путь на хосте, где будут создаваться qcow2 диски
* ``disk_pool_name``: str, optional, default=additional - имя libvirt disk pool
* ``username``: str, optional, default=u - имя пользователя для SSH
* ``password``: str, optional, default=1 - пароль пользователя

Структура ``additional_disks``:

* ``size``: str|int, optional - размер qcow2 диска в GB (default 10)
* ``device``: str, optional - путь к блочному устройству хоста (например ``/dev/vdb``)
* ``fs_type``: str, optional - тип ФС (для qcow2 по умолчанию ``ext4``, для block можно указать ``KEEPFS``)
* ``mount_point``: str, optional - точка монтирования внутри ВМ

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    vms_dates = {
        'testvm1': {
            'cpu': '4',
            'ram': '4096',
            'disk': '100',
            'additional_disks': {
                # qcow2 диск (создастся в disk_path)
                'disk1': {
                    'size': '100',
                    'mount_point': '/home/testuser2',
                    'fs_type': 'ext4',
                },
                # qcow2 диск с другой ФС
                'disk2': {
                    'size': '50',
                    'mount_point': '/home/testuser3',
                    'fs_type': 'ntfs',
                },
                # физическое устройство хоста + форматирование и монтирование
                'disk3': {
                    'device': '/dev/vdb',
                    'fs_type': 'ext4',
                    'mount_point': '/vms',
                },
                # физическое устройство хоста без форматирования и монтирования (только attach)
                'disk4': {
                    'device': '/dev/vdc2',
                },
            },
        },
    }
    vms = list(vms_dates.keys())

    Libvirt.build(box='1.7.5.o', rc='1.7.5', vms=vms, vms_dates=vms_dates)

    LibvirtManager.Vm.additional_disk(
        vms_dates=vms_dates,
        disk_path='/mnt/additional_disk',
        disk_pool_name='hdd_disk_pool',
        username='u',
        password='1',
    )

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

------------------------------------------------------------------------------------------------
``Command.generator``
------------------------------------------------------------------------------------------------

Генерирует словарь команд для использования в ``Libvirt.execute``.
При ``sync=True`` команды будут выполняться последовательно через сигналы.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``command``: str|list - команда или список команд
* ``target``: str - имя ВМ или группы ВМ (``g_<groupname>``)
* ``sync``: bool, optional, default=True - последовательное (True) или асинхронное (False) выполнение
* ``block_name``: str, optional, default=None - имя блока команд

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict`` - готовый словарь команд для ``Libvirt.execute``

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    commands = LibvirtManager.Command.generator(
        command=['uname -a', 'df -h', 'uptime'],
        target='testvm1',
        sync=True,
        block_name='base checks',
    )

    # Выполнение
    Libvirt.execute(commands=commands, vms_dates=vms_dates)

.. code-block:: python

    from allta import LibvirtManager

    commands = LibvirtManager.Command.generator(
        command='sudo systemctl restart ssh',
        target='g_all',
        sync=False,
    )

    # commands можно объединять вручную с другими задачами
    print(commands)
