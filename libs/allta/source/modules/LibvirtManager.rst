LibvirtManager
=====================

Модуль ``LibvirtManager`` содержит классы, для управления ВМ под управлением Libvirt.

.. note:: 
    Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``start``
------------------------------------------------------------------------------------------------

Включают ВМ VBox

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms``: str\list - имя одной или нескольких виртуальных машин

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager

    vms_list = ['hostname1', 'hostname2']
    vms_str = 'hostname3'

    LibvirtManager.Vm.start(vms_list)
    LibvirtManager.Vm.start(vms_str)

------------------------------------------------------------------------------------------------
``bridge``
------------------------------------------------------------------------------------------------

Выключают ВМ VBox

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms_dates``: dict - Полная информация о виртуальных машинах.
* ``new_vms_dates``: dict - Информация о виртуальных машинах, только с учетом новых ip для bridge
* ``vms_dates``: str (optional) - Имя пользователя для SSH. По умолчанию "u".
* ``vms_dates``: str (optional) - Пароль для SSH. По умолчанию "1".

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    vms_dates = {
        "testvm1": {
            "cpu": "4",
            "ram": "4096",
            "ip_bridge": "10.177.103.180"
        }
    }
    vms=['testvm1']

    old = Libvirt.build(box="1.7.5.o", rc="1.7.5", vms=vms, vms_dates=vms_dates)

    LibvirtManager.Vm.bridge(vms_date=old, new_vms_date=vms_dates, username="u", password="1")

``Snapshot.create``
------------------------------------------------------------------------------------------------

Делает снимок указаных ВМ

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms``: list - список имён виртуальных машин
* ``snapshot_name``: str - имя снимка

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager

    vms_list = ['hostname1', 'hostname2']
    snapshot_name = "test"

    LibvirtManager.Snapshot.create(vms=vms_list, snapshot_name=snapshot_name)
