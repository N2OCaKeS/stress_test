LibvirtManager
=====================

Модуль ``LibvirtManager`` содержит классы, для управления ВМ под управлением Libvirt.

.. note:: 
    Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``Vm.start``
------------------------------------------------------------------------------------------------

Включают ВМ VBox

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms``: str\\list - имя одной или нескольких виртуальных машин

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager

    vms_list = ['hostname1', 'hostname2']
    vms_str = 'hostname3'

    LibvirtManager.Vm.start(vms_list)
    LibvirtManager.Vm.start(vms_str)

``Vm.bridge``
------------------------------------------------------------------------------------------------

Устанавливают тип соединения мост для ВМ Libvirt

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms_dates``: dict - Полная информация о виртуальных машинах.
* ``new_vms_dates``: dict - Информация о виртуальных машинах, только с учетом новых ip для bridge
* ``username``: str (optional) - Имя пользователя для SSH. По умолчанию "u".
* ``password``: str (optional) - Пароль для SSH. По умолчанию "1".

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    vms_dates = {
        "testvm1": {
            "cpu": "4",
            "ram": "4096",
            "ip_bridge": "10.177.103.180"
        }
    }
    vms=['testvm1']

    old = Libvirt.build(box="1.7.5.o", rc="1.7.5", vms=vms, vms_dates=vms_dates)

    LibvirtManager.Vm.bridge(vms_date=old, new_vms_date=vms_dates, username="u", password="1")

------------------------------------------------------------------------------------------------
``Vm.additional_disk``
------------------------------------------------------------------------------------------------


""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms_dates``: dict - Полная информация о виртуальных машинах.
* ``disk_path``: str(optional,default=/vms/additional_disk) - Путь на хосте где будут созданы диски для ВМ
* ``disk_pool_name``: str(optional,default=additional) - Имя Libvirt pool который будет создан в месте где создаются диски для ВМ
* ``username``: str (optional,default=u) - Имя пользователя для SSH. По умолчанию "u".
* ``password``: str (optional,default=1) - Пароль для SSH. По умолчанию "1".

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager, Libvirt

    vms_dates = {
        "testvm1": {
            "cpu": "4",
            "ram": "4096",
            "ip_bridge": "10.177.103.180",
            "disk": "100",
            "additional_disks": {
                "disk1": {
                    "size": "100",  # default 10 gb
                    "mount_point": "/home/testuser",  # default none, if default then not mount in vm
                },
                "disk2": {
                    "size": "100",  # default 10 gb
                    "mount_point": "/home/testuser2",  # default none, if default then not mount in vm
                    "fs_type": "ntfs",  # default ext4
                },
                "disk3": {
                    "size": "10",  # default 10 gb
                },
            },
        }
    }
    vms = list(vms_dates.keys())

    Libvirt.build(box="1.7.5.o", rc="1.7.5", vms=vms, vms_dates=vms_dates)

    LibvirtManager.Vm.additional_disk(vms_dates=vms_dates, disk_path="/mnt", disk_pool_name="hdd_disk_pool", username="u", password="1")

``Command.generator``
------------------------------------------------------------------------------------------------

Откатывает на указанный снимок указаные ВМ

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""


* ``command``: str|list - Список команд
* ``target``: str - Имя ВМ или группы ВМ (задается в виде g_<имя группы>)
* ``sync``: bool,optional,default=True - Показатель асинхронного или последовательного выполнения команд
* ``name_block``: str,optional,default=None - Имя блока команд

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import LibvirtManager

    command = ["sudo ls /", "sudo ls ~", "sudo ls ~"]
    target = "testvm1"
    group_target = "g_all"
    name_block = "test block"

    LibvirtManager.Command.generator(command=command, target="test", sync=True, name_block)
