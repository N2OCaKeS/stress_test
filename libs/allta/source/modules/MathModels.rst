MathModels
=====================

Модуль ``MathModels`` предоставляет утилиты для нормализации данных, аппроксимации рядов и расчёта итогового рейтинга (Total Rating) на основе набора критериев.

.. note::
   Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``normalize``
------------------------------------------------------------------------------------------------

Нормализует числовые значения в диапазон [0, 1], учитывая необязательные границы.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``values``: Iterable[float] — последовательность значений.
* ``lower``: float, optional — нижняя граница (значения ниже будут подняты).
* ``upper``: float, optional — верхняя граница (значения выше будут обрезаны).

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``list[float]`` — нормализованные значения.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Пример использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import MathModels

    data = [10, 20, 30, 40]
    norm = MathModels.normalize(data, lower=15, upper=35)
    print(norm)  # [0.0, 0.25, 0.75, 1.0]

------------------------------------------------------------------------------------------------
``approximate``
------------------------------------------------------------------------------------------------

Строит функцию аппроксимации по ряду значений.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``values``: Sequence[float] — ряд значений.
* ``kind``: str, optional, default="linear" — тип аппроксимации:
  
  * ``"linear"`` — линейный тренд (метод наименьших квадратов).
  * ``"interp"`` — линейная интерполяция между точками.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``Callable[[float], float]`` — функция f(x) для оценки значений ряда.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Пример использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import MathModels

    f_lin = MathModels.approximate([1, 4, 9, 16], kind="linear")
    f_int = MathModels.approximate([1, 4, 9, 16], kind="interp")

    print(f_lin(2.5))  # 12.5
    print(f_int(2.5))  # 12.5

------------------------------------------------------------------------------------------------
``Criterion``
------------------------------------------------------------------------------------------------

Описание метрики для Total Rating.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Поля:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``name``: str — название критерия.
* ``values``: float | Sequence[float] — одно значение или последовательность измерений.
* ``weight``: float — вес критерия (сумма весов всех критериев должна быть 1).
* ``sign``: int, optional, default=1 — 1 для позитивного критерия, -1 для негативного.
* ``lower_bound`` / ``upper_bound``: float | None — границы для нормализации (при normalize=True).

_______________________________________________________________________________________________

------------------------------------------------------------------------------------------------
``total_rating``
------------------------------------------------------------------------------------------------

Расчёт суммарного рейтинга по набору критериев.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``criteria``: Iterable[Criterion] — критерии.
* ``aggregate``: str, optional, default="mean" — как агрегировать значения критерия:
  
  * ``"mean"`` — среднее,
  * ``"last"`` — последнее,
  * ``"max"`` — максимум,
  * ``"min"`` — минимум.
* ``normalize``: bool, optional, default=False — нормализовать ли значения (по умолчанию нет).

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``tuple[float, dict]`` — итоговый рейтинг и словарь вкладов по критериям.
  Итоговое значение не опускается ниже 0: если сумма вкладов отрицательна, рейтинг обрезается до нуля, а сами вклады остаются без изменений.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="throughput", values=[500, 800], weight=0.6, sign=1),
        Criterion(name="latency", values=[120], weight=0.4, sign=-1, lower_bound=0),
    ]

    # Без нормализации
    rating_raw, contrib_raw = MathModels.total_rating(criteria, aggregate="mean", normalize=False)

    # С нормализацией
    rating_norm, contrib_norm = MathModels.total_rating(criteria, aggregate="mean", normalize=True)

    print(rating_raw, contrib_raw)
    print(rating_norm, contrib_norm)

------------------------------------------------------------------------------------------------
``to_dict``
------------------------------------------------------------------------------------------------

Удобный вывод рейтинга и вкладов в виде словаря.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* те же, что и у ``total_rating``: ``criteria``, ``aggregate``, ``normalize``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict`` c ключами ``"rating"`` и ``"contributions"``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Пример использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="cpu", values=[0.2, 0.4, 0.3], weight=0.5, sign=1),
        Criterion(name="errors", values=[5, 2, 1], weight=0.5, sign=-1, lower_bound=0),
    ]

    data = MathModels.to_dict(criteria, aggregate="mean", normalize=True)
    print(data)
