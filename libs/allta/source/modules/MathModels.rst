MathModels
=====================

Модуль ``MathModels`` предоставляет утилиты для нормализации данных, аппроксимации рядов и расчёта итогового рейтинга (Total Rating) на основе набора критериев.

.. note::
   Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``normalize``
------------------------------------------------------------------------------------------------

Нормализует значения в диапазон [0, 1] или [-1, 1] через ``sklearn.preprocessing.MinMaxScaler``.
Поддерживает числа, последовательности чисел, ``Criterion`` и список ``Criterion``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``values``: float|int|Iterable[float|int]|Criterion|Iterable[Criterion] — данные для нормализации
* ``lower``: float|int, optional — нижняя граница (значения ниже будут подняты до неё)
* ``upper``: float|int, optional — верхняя граница (значения выше будут обрезаны)
* ``target_range``: str, optional, default="0-1" — диапазон нормализации, ``"0-1"`` или ``"-1-1"``

Если передан список ``Criterion``, каждый критерий нормализуется отдельно по своим ``lower_bound``/``upper_bound``.
Если ``lower`` и ``upper`` заданы и ``lower > upper`` — возбуждается ``ValueError``.
Если ``target_range`` не равен ``"0-1"`` или ``"-1-1"`` — возбуждается ``ValueError``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``list[float]`` — если переданы числа или одиночный ``Criterion``
* ``list[Criterion]`` — если передан список ``Criterion`` (значения обновлены на нормализованные)

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import MathModels

    data = [10, 20, 30, 40]
    norm = MathModels.normalize(data, lower=15, upper=35)
    print(norm)  # [0.0, 0.25, 0.75, 1.0]

.. code-block:: python

    from allta import MathModels

    data = [10, 20, 30, 40]
    norm = MathModels.normalize(data, target_range="-1-1")
    print(norm)

.. code-block:: python

    from allta import Criterion, MathModels

    crit = Criterion(name="cpu", values=[0.2, 0.4], weight=1.0, sign=1, lower_bound=0, upper_bound=1)
    norm = MathModels.normalize(crit)
    print(norm)

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="cpu", values=[0.2, 0.4], weight=0.5, sign=1, lower_bound=0, upper_bound=1),
        Criterion(name="errors", values=[5, 2, 1], weight=0.5, sign=-1, lower_bound=0, upper_bound=10),
    ]

    normalized = MathModels.normalize(criteria)
    print(normalized)

------------------------------------------------------------------------------------------------
``normalize_criteria``
------------------------------------------------------------------------------------------------

Глобально нормализует значения всех критериев одним проходом, сохраняя структуру по критериям.
Все значения объединяются, нормализуются, затем результат разбивается обратно по исходным критериям.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``criteria``: Iterable[Criterion] — набор критериев
* ``lower``: float|int, optional — общая нижняя граница
* ``upper``: float|int, optional — общая верхняя граница
* ``target_range``: str, optional, default="0-1" — диапазон нормализации

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict[str, list[float]]`` — нормализованные значения по каждому критерию

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="throughput", values=[500, 800], weight=0.6, sign=1),
        Criterion(name="latency", values=[120, 150], weight=0.4, sign=-1),
    ]

    data = MathModels.normalize_criteria(criteria, target_range="0-1")
    print(data)

------------------------------------------------------------------------------------------------
``approximate``
------------------------------------------------------------------------------------------------

Строит полиномиальную аппроксимацию по значениям ``x`` и ``y``.
Степень полинома автоматически понижается при проблемах с ранком.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``x``: Sequence[float] | Criterion — значения оси X
* ``y``: Sequence[float] | Criterion — значения метрики
* ``degree``: int, optional, default=10 — максимальная степень полинома

Длины ``x`` и ``y`` должны совпадать, для аппроксимации нужно минимум две точки.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``np.poly1d`` — функция ``f(x)`` для оценки значений ряда

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import MathModels

    x = [1, 2, 3, 4]
    y = [1, 4, 9, 16]

    f = MathModels.approximate(x, y, degree=3)
    print(f(2.5))

.. code-block:: python

    from allta import Criterion, MathModels

    x = Criterion(name="x", values=[1, 2, 3, 4], weight=1.0)
    y = Criterion(name="y", values=[1, 4, 9, 16], weight=1.0)

    f = MathModels.approximate(x=x, y=y, degree=3)
    print(f(2.5))

------------------------------------------------------------------------------------------------
``Criterion``
------------------------------------------------------------------------------------------------

Описание метрики для Total Rating.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Поля:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``name``: str — название критерия
* ``values``: float | Sequence[float] — одно значение или последовательность измерений
* ``weight``: float — вес критерия (сумма весов всех критериев должна быть в диапазоне (0.9; 1])
* ``sign``: int, optional, default=1 — 1 для позитивного критерия, -1 для негативного
* ``lower_bound`` / ``upper_bound``: float | None — границы для нормализации

_______________________________________________________________________________________________

------------------------------------------------------------------------------------------------
``total_rating``
------------------------------------------------------------------------------------------------

Расчёт суммарного рейтинга по набору критериев.
Значения всегда нормализуются внутри функции (параметр ``normalize`` оставлен для совместимости).

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``criteria``: Iterable[Criterion] — критерии
* ``aggregate``: str, optional, default="mean" — как агрегировать значения критерия:
  ``"mean"``, ``"last"``, ``"max"``, ``"min"``
* ``normalize``: bool, optional, default=True — сохраняется для совместимости (нормализация всегда выполняется)
* ``normalize_range``: str, optional, default="0-1" — диапазон нормализации (``"0-1"`` или ``"-1-1"``)

Сумма весов критериев должна быть в диапазоне (0.9; 1], все веса должны быть положительными.

Формула (после нормализации):

* Позитивный критерий (``sign >= 0``): ``contrib = weight * (y + epsilon)``
* Негативный критерий (``sign < 0``): ``contrib = weight / (y + epsilon)``

Где ``y`` — агрегированное значение критерия, ``epsilon = 0.001``.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``tuple[float, dict]`` — итоговый рейтинг и словарь вкладов по критериям

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="throughput", values=[500, 800], weight=0.6, sign=1),
        Criterion(name="latency", values=[120], weight=0.4, sign=-1, lower_bound=0),
    ]

    rating, contributions = MathModels.total_rating(
        criteria,
        aggregate="mean",
        normalize_range="0-1",
    )

    print(rating)
    print(contributions)

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="success", values=[0.9, 0.95], weight=0.5, sign=1),
        Criterion(name="errors", values=[0.1, 0.05], weight=0.5, sign=-1),
    ]

    rating, contributions = MathModels.total_rating(
        criteria,
        aggregate="last",
        normalize_range="-1-1",
    )

    print(rating)
    print(contributions)

------------------------------------------------------------------------------------------------
``to_dict``
------------------------------------------------------------------------------------------------

Удобный вывод рейтинга и вкладов в виде словаря.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* те же, что и у ``total_rating``: ``criteria``, ``aggregate``, ``normalize``
* дополнительный аргумент ``normalize_range`` также пробрасывается и поддерживает значения ``"0-1"`` или ``"-1-1"``

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``dict`` c ключами ``"rating"`` и ``"contributions"``

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import Criterion, MathModels

    criteria = [
        Criterion(name="cpu", values=[0.2, 0.4, 0.3], weight=0.5, sign=1),
        Criterion(name="errors", values=[5, 2, 1], weight=0.5, sign=-1, lower_bound=0),
    ]

    data = MathModels.to_dict(criteria, aggregate="mean", normalize=True)
    print(data)
