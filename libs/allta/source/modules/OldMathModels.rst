OldMathModels
=====================

Модуль ``OldMathModels`` документирует старую математическую модель ``OldMathModel``.

.. note::
   Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``OldMathModel``
------------------------------------------------------------------------------------------------

Класс ``OldMathModel`` реализует старую схему расчёта рейтинга.

Основные шаги расчёта для каждого критерия:

* min-max нормализация в рамках ``bounds``
* полиномиальная аппроксимация (``max_degree`` по умолчанию 3, с понижением при ``RankWarning``)
* интеграл по интервалу ``x_values``
* умножение на ``weight``
* для ``negative`` критериев: применение степени ``-1`` к финальному вкладу

Отличие от ``MathModel``: в старой модели нет ``calc_power`` и нет odds-преобразования.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Конструктор
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

``OldMathModel(max_degree=3, normalize_integral=False, epsilon=1e-12)``

* ``max_degree``: максимальная степень полинома для аппроксимации
* ``normalize_integral``: делить ли интеграл на длину интервала
* ``epsilon``: защита от деления на ноль при ``negative`` критериях

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Основные методы
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``add_criterion(name, iterations, values, weight, negative, bounds, max_degree=None)``
  Добавляет критерий.

* ``total_rating()``
  Возвращает итоговый рейтинг и детализацию по критериям.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Пример использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import OldMathModel

    x_values = [100, 200, 300, 400, 500]

    model = OldMathModel(max_degree=3, normalize_integral=False)
    model.add_criterion(
        "la",
        iterations=x_values,
        values=[8.482, 17.97, 31.627, 46.598, 61.064],
        weight=0.33,
        negative=True,
        bounds=(0.0, 700.0),
    )
    model.add_criterion(
        "tps1",
        iterations=x_values,
        values=[11789.016818, 11129.553002, 9485.622431, 8584.144843, 8188.122856],
        weight=0.83,
        negative=False,
        bounds=(0.0, 140000.0),
    )
    model.add_criterion(
        "tps2",
        iterations=x_values,
        values=[11791.092539, 11130.303031, 9486.123688, 8584.491484, 8188.385106],
        weight=0.83,
        negative=False,
        bounds=(0.0, 140000.0),
    )

    result = model.total_rating()
    print(result["total_rating"])
