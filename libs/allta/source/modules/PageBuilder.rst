PageBuilder
=====================

.. note::
   Автор: команда ``allta``. Конструктор HTML-страниц для публикации в Confluence.
   ``add_chart`` автоматически строит макрос Table Filter and Charts ``table-chart``.

Использование
-------------

.. code-block:: python

    from allta import PageBuilder

    builder = PageBuilder(title="Demo")
    builder.add_heading("Кратко")
    builder.add_paragraph("Описание отчёта")
    builder.add_header_table([
        {"label": "Params", "value": {"items": ["Users: 3000"]}},
        {"label": "ARM", "value": {"stand_number": "10"}},
    ])
    builder.add_table({
        "title": "Быстрые факты",
        "headers": ["Метрика", "Значение"],
        "rows": [["TPS", 42], ["Ошибки %", "0.1"]],
    })
    html = builder.render()

------------------------------------------------------------------------------------------------
``add_raw_html(html: str)``
------------------------------------------------------------------------------------------------

Добавляет произвольный HTML-фрагмент без обработки.

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_raw_html('<div style="color:red">Warning</div>')

------------------------------------------------------------------------------------------------
``add_heading(text: str, level: int = 2)``
------------------------------------------------------------------------------------------------

Добавляет заголовок уровня ``h1-h6``.

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_heading("Сводка", level=3)

------------------------------------------------------------------------------------------------
``add_paragraph(text: str)``
------------------------------------------------------------------------------------------------

Добавляет параграф, строки разделяются через ``<br/>``.

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_paragraph("Параграф\nс переносом строки")

------------------------------------------------------------------------------------------------
``add_unordered_list(items: Iterable[str])``
------------------------------------------------------------------------------------------------

Создаёт маркированный список.

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_unordered_list(["item1", "item2"])

------------------------------------------------------------------------------------------------
``add_ordered_list(items: Iterable[str])``
------------------------------------------------------------------------------------------------

Создаёт нумерованный список.

Возвращает: текущий ``PageBuilder``.

------------------------------------------------------------------------------------------------
``add_table(table_spec: Mapping)``
------------------------------------------------------------------------------------------------

Строит таблицу по словарю (``headers``, ``rows``, ``title`` и т.д.).

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_table({
        "title": "Top metrics",
        "headers": ["Name", "Value"],
        "rows": [
            {"Name": "TPS", "Value": "42"},
            {"Name": "Latency", "Value": "250ms"},
        ],
    })

------------------------------------------------------------------------------------------------
``add_header_table(rows, defaults=None)``
------------------------------------------------------------------------------------------------

Формирует «шапку» отчёта. Автоматически добавляет строки ``Astra version`` и ``Kernel``.
Строка ``ARM`` заполняется по ``stand_number`` и всегда располагается перед ``Lead time``.
Прежнее имя ``add_details_table`` сохранено как алиас.

Возвращает: текущий ``PageBuilder``.

.. code-block:: python

    builder.add_header_table([
        {"label": "Params", "value": {"items": ["Users: 3000"]}},
        {"label": "ARM", "value": {"stand_number": "10"}},
        {"label": "Lead time", "value": "00:12:34"},
    ])

------------------------------------------------------------------------------------------------
``add_attachment(file_path, title=None, description=None, display=True)``
------------------------------------------------------------------------------------------------

Регистрирует файл-вложение и добавляет блок на страницу.

Возвращает: текущий ``PageBuilder``.

------------------------------------------------------------------------------------------------
``add_gallery(images, columns=2)``
------------------------------------------------------------------------------------------------

Строит таблицу с изображениями в несколько колонок. Каждый элемент может содержать
``title``, ``caption``, ``description`` и ``attachment``.

Возвращает: текущий ``PageBuilder``.

------------------------------------------------------------------------------------------------
``add_chart(chart_spec, columns=1)``
------------------------------------------------------------------------------------------------

Встраивает макрос Table Filter and Charts ``table-chart``. ``chart_spec`` может быть словарём
или списком словарей; для списка графики автоматически раскладываются по указанному числу
колонок. Поддерживаются параметры ``x_key``, ``series``, ``colors``/``series_colors``,
``per_category_colors``, ``time_series``, ``series_orientation`` и ``params`` (прокидываются
напрямую в макрос).

------------------------------------------------------------------------------------------------
``add_gallery`` / ``add_attachment`` / ``add_chart`` Примеры
------------------------------------------------------------------------------------------------

.. code-block:: python

    builder.add_gallery([
        {"title": "Стэнд", "caption": "Внешний вид", "src": "img.png"},
        {"title": "Графики", "caption": "Chart", "src": "img2.png"},
    ], columns=2)

    builder.add_chart([
        {
            "title": "Throughput",
            "type": "line",
            "x_key": "T",
            "series": ["avg", "p95"],
            "series_colors": {"avg": "#0052CC", "p95": "#36B37E"},
            "data": [
                {"T": "T+00", "avg": 8.1, "p95": 8.7},
                {"T": "T+05", "avg": 8.3, "p95": 8.8},
            ],
        },
        {
            "title": "Errors %",
            "type": "column",
            "x_key": "Release",
            "series": ["value"],
            "per_category_colors": {"r1": "#FF5630", "r2": "#FFAB00"},
            "data": [
                {"Release": "r1", "value": 1.2},
                {"Release": "r2", "value": 0.4},
            ],
        },
    ], columns=2)

------------------------------------------------------------------------------------------------
``render()``
------------------------------------------------------------------------------------------------

Возвращает итоговый HTML.

------------------------------------------------------------------------------------------------
``render_to_file(path)``
------------------------------------------------------------------------------------------------

Сохраняет HTML в файл и возвращает ``Path``.
