SystemCommands
=====================

Модуль ``SystemCommands`` содержит функции и классы, отвечающие за выполнение системных команд на локальной машине.

.. note:: 
    Автор: ``dtimonin``

------------------------------------------------
``check_output_command``
------------------------------------------------

Выполняет команду на хосте от текущего пользователя с подробным выводом. Если возникли ошибки при выполнении возвращает информацию об ошибке.

""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""

* ``command``: str - команда которая должна быть выполнена

""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""

* ``str`` - вывод команды или сообщение об ошибке

""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""

.. code-block:: python


    from allta import SystemCommands

    # Пример выполнения команды 'ls -l'
    result = SystemCommand.check_output_command("ls -l")
    print(result)

``cmd``
------------------------------------------------

Выполняет команду на хосте от текущего пользователя без обработки результата.

""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""

* ``command``: str - команда которая должна быть выполнена

""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""

* ``subprocess.run`` - код завершения

""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""

.. code-block:: python


    from allta import SystemCommands

    # Пример выполнения команды 'ls -l'
    result = SystemCommand.cmd("ls -l")
    print(result)

------------------------------------------------
``check_output_command_with_returncode``
------------------------------------------------

Выполняет команду на хосте от текущего пользователя, и возвращает массив из кода и вывода или ошибки.

""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""

* ``command``: str - команда которая должна быть выполнена

""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""

* ``list`` - Массив из двух элементов:
                - int: Код возврата (0 = успех, не 0 = ошибка)
                - str: Вывод команды (stdout) или ошибки (stderr), если она была.

""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""

.. code-block:: python


    from allta import SystemCommands

    # Пример выполнения команды 'ls -l'
    result = SystemCommand.check_output_command_with_returncode("ls -l")
    print(result[0], result[1])
