VBoxManager
=====================

Класс для управления ВМ под управлением VBox

.. note:: 
    Автор: ``mfilippenko``

------------------------------------------------------------------------------------------------
``power_on``
------------------------------------------------------------------------------------------------

Включают ВМ VBox

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``vms``: str\list - имя одной или нескольких виртуальных машин

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import VBoxManager

    vms_list = ['hostname1', 'hostname2']
    vms_str = 'hostname3'

    VBoxManager.power_on(vms_list)
    VBoxManager.power_on(vms_str)
