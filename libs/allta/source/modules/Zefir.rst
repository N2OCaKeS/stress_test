Zefir
=====

.. note::
   Модуль ``Zefir`` в текущей версии библиотеки экспортирует наружу только
   класс ``UploaderZC``.
   Реализация повторяет legacy-поведение старого ``kernel/libs/zefir.py``:
   при импорте модуля выполняются запросы для получения URL Jira/Confluence,
   а при обновлении статуса автоматически строится и публикуется итоговая
   таблица результатов.

Назначение
----------

``UploaderZC`` используется как совместимая обёртка для сценария stress-теста:

* проверяет доступность Jira и Confluence;
* находит нужный тест-кейс в Zephyr по имени прогона и имени кейса;
* выставляет статус результата теста;
* после обновления статуса инициирует сборку HTML-таблицы результатов и её
  публикацию в Confluence.

Важно:

* Публичным интерфейсом является только ``UploaderZC``.
* Внутренние классы и функции модуля не предназначены для прямого вызова.
* Несмотря на ``None`` в сигнатуре ряда параметров, для реального рабочего
  сценария обычно должны быть заданы как минимум ``folder_tree_id``,
  ``test_cycle_version``, ``test_cycle_name``, ``test_case_name``,
  ``basic_auth``, ``username`` и ``token``.
* Параметры ``grade_stand``, ``conf_space``, ``conf_parent_page``,
  ``conf_new_page_name`` и ``testname`` сохранены в интерфейсе для
  совместимости, но текущая логика ``UploaderZC`` их не использует.

Использование
-------------

.. code-block:: python

    from allta import UploaderZC

    uploader = UploaderZC(
        folder_tree_id=2773,
        test_cycle_version="1.8.4.46",
        test_cycle_name="1.8.4.46_smolensk_6.1.158-1-generic_stand12",
        test_case_name="vpn smoke",
        username="user",
        basic_auth="Basic XXX",
        token="TOKEN",
    )

    uploader.upload_test_cycle_status("progress")

------------------------------------------------------------------------------------------------
``UploaderZC``
------------------------------------------------------------------------------------------------

Совместимая внешняя обёртка над внутренней логикой ``zefir.py``.
Класс хранит параметры тестового прогона и предоставляет методы для
обновления статуса кейса в Zephyr.

------------------------------------------------------------------------------------------------
``__init__(folder_tree_id: int | str | None = None, test_cycle_version: str | None = None, test_cycle_name: str | None = None, test_case_name: str | None = None, username: str | None = None, basic_auth: str | None = None, token: str | None = None``
------------------------------------------------------------------------------------------------

Создаёт объект для последующего обновления статуса тест-кейса.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``folder_tree_id``: ``int | str | None`` - ID папки дерева прогонов в Zephyr/Jira.
* ``test_cycle_version``: ``str | None`` - версия тестового цикла, например ``1.8.4.46``.
* ``test_cycle_name``: ``str | None`` - имя тестового цикла в Zephyr.
* ``test_case_name``: ``str | None`` - имя тест-кейса внутри прогона.
* ``username``: ``str | None`` - имя пользователя Confluence.
* ``basic_auth``: ``str | None`` - значение заголовка ``Authorization`` для Jira.
* ``token``: ``str | None`` - токен доступа в Confluence.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    from allta import UploaderZC

    uploader = UploaderZC(
        folder_tree_id=2773,
        test_cycle_version="1.8.4.46",

        test_case_name="vpn smoke",
        username="user",
        basic_auth="Basic XXX",
        token="TOKEN",
    )

------------------------------------------------------------------------------------------------
``test_cycle_status_changer(status: str)``
------------------------------------------------------------------------------------------------

Меняет статус тест-кейса и сразу запускает построение таблицы результатов.

Поддерживаемые строковые значения статуса:

* ``"pass"``
* ``"fail"``
* ``"progress"``

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``status``: ``str`` - новый статус тест-кейса.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``int`` - всегда ``0`` после выполнения текущей логики метода.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    uploader.test_cycle_status_changer("progress")

------------------------------------------------------------------------------------------------
``upload_test_cycle_status(zefir_status: str)``
------------------------------------------------------------------------------------------------

Ожидает доступности Jira и Confluence, затем обновляет статус тест-кейса.
Если сервисы временно недоступны, выполняет повторные попытки и пишет ошибки
в ``JIRA_ERROR.log``.

Поддерживаемые строковые значения статуса:

* ``"pass"``
* ``"fail"``
* ``"progress"``

Внутренние параметры ожидания в текущей реализации захардкожены:

* ожидание до ``30`` минут;
* период опроса ``180`` секунд.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Принимаемые аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``zefir_status``: ``str`` - статус, который нужно установить тест-кейсу.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Возвращает аргументы:
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

* ``None`` - метод не возвращает значение.

""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""
Примеры использования
""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""""

.. code-block:: python

    uploader.upload_test_cycle_status("pass")
