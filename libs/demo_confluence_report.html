Сводка

Эта страница показывает, как собрать отчёт из чистого Python без шаблонов.
Все блоки описываются через методы builder'a.

  1. Подготовка стенда
  2. Запуск тестов
  3. Сбор результатов
  4. Публикация в Confluence
