## Публикация результатов нагрузочного тестирования

### После выполнения тестового сценария предусмотрена возможность автоматической публикации результатов на https://life.astralinux.ru

`venv/bin/python3 *_publish.py`

- **--userbane**  - имя пользователя
- **--token**  - токен пользователя (необходимо предварительно сгенерировать)
- **--confluence-space** - пространство
- **--confluence-parent-page** - название родительской страницы
- **--confluence-new-page** - название новой страницы
- **--jira-issue** - номер задачи к которой будет приклепленна ссылка на отчет
- **--package** - название тестируемого пакета
- **--report-path** - директория в которой находится отчет
- **--template-path** - директория в которой находятся файлы с шаблонами оформления отчета
- **--info-path** - файл с информацией о версии ОС, режима защищенности, версии ядра, версии пакета, фактическом времени выполнения тестового сценария
- **--tarfile-path** - путь до архива с отчетом
- **--arm-name** - название грейда и его инв. номер согласно https://life.astralinux.ru/pages/viewpage.action?pageId=150960164
- **--arm-proccessor** - информация о процессоре грейда
- **--arm-memory** - информация об оперативной памяти грейда в Гб
- **--arm-storage** - информация о системном хранилище грейда
