# get_stat.py

## Подсчет основных статистических параметров на основании имеющихся результатов

После выполнения тестового сценария предусмотрена возможность автоматической публикации результатов на https://life.astralinux.ru.
Далее возможно воспользоваться данным сценарием для промежуточного подсчета статистических параметров, на основании которых можно провести выбраковку результатов.

Вывод результатов выполнения скрипта можно организовать как в виде .html (**не содержит `<meta charset="utf-8">`**), так и просто в консоль или же всё вместе.

### Предварительные действия

Выполнить `prep.sh` для настройки **venv** и установки зависимостей.

### Запуск

`venv/bin/python get_stat.py`

- **--username**  - имя пользователя Confluence
- **--token**  - токен пользователя Confluence(необходимо предварительно сгенерировать)
- **--page-pattern** - начальное слово-идентификатор в названии страницы (чаше тестируемого название компонента)
- **--component** - пересчет статистических параметров основываясь на данных из таблиц со страниц "Статистика по апдейтам" 
- **--confluence-space** - имя пространста Confluence
- **--save-to-html** - создать .html
- **--console-output** - вывести результаты в консоль
- **--verbose** - режим вывода промежуточных результатов по ходу выполнения
