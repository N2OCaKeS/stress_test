Описание

Цель UnixBench — предоставить базовый индикатор производительности Unix-подобной системы. Тесты для многопроцессорной системы. По умолчанию выбранные тесты выполняются дважды - один раз с одной копией каждой тестовой программы, запущенной одновременно, и один раз с N копиями, где N - количество CPU. Это сделано для того, чтобы вы могли оценить: * производительность вашей системы при выполнении одной задачи * производительность вашей системы при выполнении нескольких задач * выйгрыш от реализации вашей системы параллельной обработки
