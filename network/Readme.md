# Network_benchmark

Комплекс нагрузочного тестирования сетевых сервисов.

##

### Test 1

### NetworkLoad

В тесте производится оценка сетевой производительности с помощью `iperf` при разных значениях параметра ядра `init_on_free`.
Сравниваются результаты в базовом состоянии (до изменения параметра) и после установки `init_on_free=off`.

Тестовый сценарий:

- На `testvm1` запускается `iperf` сервер.
- На `testvm2` запускается `iperf` клиент.
- Выполняется серия замеров в базовом состоянии.
- На `testvm1` устанавливается `init_on_free=off` и выполняется reboot.
- Выполняется вторая серия замеров.
- Результаты двух серий сравниваются между собой.

Параметры теста:

- Сравниваемые режимы: baseline и `init_on_free=off`
- Количество повторений нагрузки: `10` (`ITERATIONS`)
- Инструмент генерации нагрузки: `iperf`

#### Зависимости

- iperf

#### Проведение тестирования

Тестирование выполняется в автоматическом режиме через оркестратор ALLTA.

#### Обработка результатов

Результаты сохраняются в логи `iperf` и используются для сравнения производительности между режимами `init_on_free`.
