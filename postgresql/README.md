# PostgreSQL_benchmark
Комплекс нагрузочного тестирования, направленный на тестирование БД PostgreSQL.


### Test 1
### PostgreSQL_benchmark
Система нагрузочного тестирования БД PostgreSQL с использованием функционала **pgbench**.   
Подключение к базе происходит при помощи сетевого сокета.  
Выполняется в режиме орел.  
Используется один итерационный цикл по кол-ву клиентов с зафиксированными параметрами.   
  - масштабирование = 500 
  - транзакции = 100000 
  - потоки = 200 
  - клиенты = 100 - 500 (шаг равен 100)


### Test 2
### PostgreSQL_benchmark audit-off
Система нагрузочного тестирования БД PostgreSQL с использованием функционала **pgbench**.   
Подключение к базе происходит при помощи сетевого сокета.  
Выполняется в режиме орел с отключенным аудитом.    
Используется один итерационный цикл по кол-ву клиентов с зафиксированными параметрами.   
  - масштабирование = 500 
  - транзакции = 100000 
  - потоки = 200 
  - клиенты = 100 - 500 (шаг равен 100)


### Test 3
### PostgreSQL_benchmark balance
Тестирование работы PostgreSQL в отказоустойчивом кластере и обновление БД при сохранении доступности.  
Используется самописный аналог **pgbench** т.к. стандартный при отключении БД падает с ошибкой.  
Достижение кворума гарантируется путём инстанцирования трёх экземпляров базы данных и трёх балансировщиков нагрузки,  
интегрированных в область домена.  



### Test 4
### PostgreSQL_benchmark kernels
Система нагрузочного тестирования БД PostgreSQL с использованием функционала **pgbench**.  
При тестирвоании производится проверка деградации производительности БД на многоядерных системах.  
Тестирование проводится на 8, 16, 24 и 32 ядрах. В последствии производится оценка роста производительности  
при увеличении количества ядер (критерий прохождения на данный момент: 15% к предыдущему).   
Расчет усредненных показателей производится по данной методике:

-  [Расчет результатов PGbench](https://life.astralinux.ru/pages/viewpage.action?pageId=237097452&src=contextnavpagetreemode)
