# PostgreSQL Benchmark

Система нагрузочного тестирования базы данных PostgreSQL с использованием утилиты `pgbench`.  
Подключение к базе данных происходит при помощи сетевого сокета.    
Тестирование выполнено в единственном итерационном цикле с заданными параметрами:    

- Масштабирование: 500    
- Время транзакций: 30 секунд    
- Потоков: 300    
- Клиентов: 300    

---    

### Описание

Автоматизированная система нагрузочного тестирования PostgreSQL с возможностью изменения конфигурации через файл настроек `psql_test.conf`.  
Подготовка окружения и проведение тестов автоматизированы.    

#### Требования для запуска:
- Версия Python должна быть не ниже 3.10    
- Необходима установка соответствующих репозиториев дистрибутива тестируемой операционной системы.   
- Тестируемая ОС должна находиться в режиме **Смоленск**.    
- МРД должен быть активирован.    

#### Запуск:
Если версия Python ниже 3.10, для установки Python3.12 используйте скрипт   
Запускайте из основной директории с тестом    
```bash
sudo bash install_python.sh
```    

Запускайте из основной директории с тестом   
```bash
source Python-3.12.1/venv/bin/activate
sudo python3.12 run.py
```   

#### run.py:   
Скрипт содержит набор методов (операций), которые выполняются последовательно    
Вызов любой операции можно предварительно отключить/включить переведя соответствующее значение в False или True    
Может пригодиться при повторных запусках, когда не нужно что-то проверять, устанавливать или очистке окружения    
Для активации раскомментировать нужное    
Пример:   
```python
test.host_prepare = False
```
