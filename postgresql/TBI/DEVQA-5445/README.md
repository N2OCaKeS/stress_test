# PostgreSQL Benchmark

Система нагрузочного тестирования базы данных PostgreSQL с использованием доработанной версии утилиты `pgbench`.  
Подключение к базе данных происходит при помощи сетевого сокета.    
Тестирование выполнено в единственном итерационном цикле с заданными параметрами:    

- Масштабирование: 500    
- Время транзакций: 30 секунд    
- Потоков: 300    
- Клиентов: 300    

---    

### Описание

Автоматизированная система нагрузочного тестирования PostgreSQL с возможностью изменения конфигурации через файл настроек `psql_test.conf`.  
Подготовка окружения и проведение тестов полностью автоматизированы.    

#### Требования для запуска:
- Необходима установка соответствующих репозиториев дистрибутива тестируемой операционной системы.   
- Тестируемая ОС должна находиться в режиме **Смоленск**.    
- МРД должен быть активирован.    

#### Запуск:
Запускайте из основной директории с тестом   
```bash
sudo python3 run.py
```
