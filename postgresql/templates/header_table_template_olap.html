Описание

Тестирование работы PostgreSQL c olap запросами, и замером времени каждого запроса. Нагрузка идет запросами по очереди с повторением каждого запроса 3 раза. В тестировании участвуют сложные аналитические запросы. Результатом тестирования являются таблицы значений:

  • hard_query: комплексный поиск пакетов и исходников по подстроке lib с JOIN, проверкой нескольких текстовых полей и сортировкой по вычисляемому md5;
  • order_query: полная выборка из main.build_packages с тяжёлой сортировкой по вычисляемому md5, длине поля files и дате создания;
  • substring_search_query: поиск бинарных пакетов, в названии которых встречается подстрока lib;
  • join_query: соединение исходных пакетов и бинарных пакетов для сборки debian.sid.unstable;
  • oom_form_am289n04_query: тяжёлый процедурный пересчёт по большому набору ДСЕ: цикл по записям, вложенные расчёты маршрутов, временные таблицы и массовые DELETE/INSERT, создающие высокую CPU, memory и I/O нагрузку.
