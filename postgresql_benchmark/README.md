# Нагрузочное тестирование.
## PostgreSQL_benchmark
Система нагрузочного тестирования БД PostgreSQL с использованием функционала **pgbench**. 
После проведения тестирования автоматически генерируется архив с отчётом.
### **Зависимости**
### **Настройка тестовой машины**
Для настройки стендовой машины перед проведение тестирования необходимо склонировать сей проект.
Далее необходимо вписать путь до проекта в переменную **SCRIPT_DIR** в файле psb_conf.py.
    
    SCRIPT_DIR = '/media/sf_git/stress_test/postgresql_benchmark'

Далее необходимо создать виртуальное окружение.

`cd postgresql_benchmark && ./psb_prep.sh`

### **Запуск**
На данный момент реализован один набор тестов.

- **base** - Набор используется по умолчанию. Включает в себя тестирование системы на встроенных сценариях pgbench.

И два режима тестирования.

- **default** - Режим используется по умолчанию. Режим, при котором используется один итерационный цикл по кол-ву клиентов с зафиксированными параметрами. Конфигурация актуальна для текущей стендовой машины.
  - масштабирование = 500 
  - транзакции = 100000 
  - потоки = 200 
  - клиенты = 100 - 10000 (шаг увеличивается в геометрической прогрессии x2)

- **extended** - режим, при котором используются итерационные циклы, по всем параметрам: масштабирование, транзакции, потоки, клиенты. Циклы определяют предельные значения для каждого параметра, а затем запускают итоговый тест с этими значениями.
  Параметры указываются в конфигурационном файле **psb_conf.py**


    SCALE_FACTOR

    SCALE_FACTOR_STEP

    LIMITE_SCALE_FACTOR

    TRANSACTIONS

    TRANSACTIONS_STEP

    LIMITE_TRANSACTIONS

    THREADS

    THREADS_STEP

    LIMITE_THREADS

    CLIENTS

    CLIENTS_STEP

    LIMITE_CLIENTS


Запуск теста производить от суперпользователя (root):

`cd postgresql_benchmark`

`venv/bin/python3 psb_run.py`

- **--dbprep**  - в случае необходимости настройки тестовой машины
- **--сleaner**  - в случае необходимости "очистки" машины после проведения тестирования
- **--testlist** - в случае выбора набора тестов
- **--mode** - в случае выбора режима тестирования

### **Проведение тестирования**
Во время проведения тестирования в терминал выводятся сообщения о прохождении каждого теста c пометкой **pass / fail**
### **Обработка результатов**
После прохождения теста в текущей папке postgresql_benchmark создается .tar с результатами тестирования в виде графиков и таблиц.
Общий отчет собран в файле main_report.html
