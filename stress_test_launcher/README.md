# Система автоматизации нагрузочного тестирования
Данная система позволяет автоматически запускать тестовые сценарии на каждом отдельном стенде и выкладывать результаты на https://life.astralinux.ru, также дублировать архив на ftp-сервер в директорию /stress_reports.

Данная система проверяет соотвествие указанных параметров, таких как:
 - версию ОС, в случае не соответсвия выполнение на этом стенде завершается.
 - версию ядра ОС, в случае не соотвествия указанная версия устанавливается по умолчанию.
 - режим защищенности ОС, в случае не соотвествия происходит смена на указанный режим защищенности.

### **Предварительные действия**

 `sudo apt install ansible`

 `pip3 install atlassian-python-api`

 Подключиться по ssh самостоятельно к каждому стенду для получения записи fingerprint

### **Конфигурирование**
Необходимо указать ip адреса стендов в файле **hosts.yml**. В случае добавления новых стендов или изменения их названия в файле hosts.yml, необходимо внести соответсвующие изменения в файл **launcher_conf.py**.

**Если после последнего коммита изменялись файлы конфигурации тестовых сценариев, необходимо их заменить в соответсвующих директориях**.

### **Запуск**

 `python3 launcher.py` 

При запуске выбрать стенды, для них указать тестовые сценарии, название снимка для восстановления, версию ОС, версию ядра, режим защищенности.

После запуска появляется директория **logs** в ней создаются файлы с названием стенда. В эти файлы записывается информация о ходе выполнения сценария.

Работает в фоновом режиме (После запуска появится возможность вводить команды в терминале)
