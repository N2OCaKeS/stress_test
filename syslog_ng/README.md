# Syslog-NG_benchmark
Система нагрузочного тестирования Syslog-NG.   


### Test 1
### Syslog-NG
Создается нагрузка посредством генерации различных событий демонами ...

-  atlassian-python-api
-  pandas 
-  scikit-learn 
-  requests
-  numpy
