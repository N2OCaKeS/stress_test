# Create testrun by changelog

## Данный сервис, возращает список компонентов, в которых были изменения, опубликованные в репозитории.

В конфигурационном файле `package_groups.py` описан словарь - компонент: список пакетов, в которых реализован функционал данного компонента. При необходимости можно редактировать или дополнять.


При обращении на url `/get_components_for_testrun_by_changelog` (get request) необходимо указать обязательнный аргумент `astra_linux_build_version`. <br> В ответе будет список из компонентов в которых были изменения, описанные в `package_groups.py`. <br> Если указать аргумент `return_dct_component_with_packages` (по умолчанию `false`) вернет словарь - компонент: список пакетов в которых были изменения. 


В данном сервисе реализована возможность добавления первого уровеня зависимостей пакета, в котором реализуется функционал конкретного компонента. <br> По умолчанию `first_level_dependencies` установлен в `true`. Для того чтобы убрать первый уровень завимостей необходимо установить данный аргумент в `false`.

### Для того чтобы развернуть сервис, необходимо:
1. `sudo apt install -y docker.io docker-compose`
2. `cd testrun_changelog`
3. `sudo docker-compose build`
4. `sudo docker-compose up`
