# QEMU/KVM/Libvirt_benchmark

Комплекс нагрузочного тестирования, направленный на тестирование различных компонентов QEMU/KVM/Libvirt.


### Test 1
### Steal_time
В тесте производится оценка влияния простых операций на производительность CPU в ВМ без нагрузки и с нагрузкой.   

Под простыми операциями подразумевается обращение к инструкции cpuid через ассемблер и получение информации, такой как     
вендор процессора, серийный номер, поддерживаемые функции и т.д.    
Во время теста оценивается steal time на подконтрольных ВМ, а также общее влияние на утилизацию CPU хоста.    
Выполняется в режиме **орел**.  


### Test 2
### FIO
В тесте производится оценка производительности дисковой системы с помощью утилиты fio (Flexible I/O tester).    
Тестовый сценарий:    
Случайное чтение/запись (random read/write) файлов размером 4 Кб.    
Прямой асинхронный ввод/вывод (aio=direct), который минимизирует кэширование в операционной системе для более реалистичной нагрузки на диск.      
Операции с различными уровнями глубины очереди (queue-depth), которые определяют количество операций ввода/вывода, ожидающих выполнения.    
Выполняется в режиме **орел**.    


### Test 3
### UnixBench
В тесте используется бенчмарк, который предоставляет базовый индикатор производительности Unix-подобной системы.     
Тесты для многопроцессорной системы. Выполняются на ВМ.     
По умолчанию выбранные тесты выполняются трижды - один раз с 4 копиями каждой тестовой программы,     
запущенной одновременно, далее с 8 и 12 копиями при выделенных 8 CPU.     
Выполняется в режиме **орел**.     


### Test 4
### PingPong
В тесте один процесс отправляет небольшой объем данных другому процессу, который в ответ отправляет эти данные обратно.     
Скорость обмена определяется как количество обменов за единицу времени.    
Целью теста является оценка пропускной способности и задержки между двумя процессами в виртуальной машине.   
Выполняется в режиме **орел**.

### Test 5
### Large_disk_FIO
В тесте производится оценка производительности дисковой системы(большого размера без кэширования) с помощью утилиты fio (Flexible I/O tester).
Тестовый сценарий:    
Случайное чтение/запись (random read/write) файлов размером от 1Гб до 1Тб.    
Прямой асинхронный ввод/вывод (aio=direct), который минимизирует кэширование в операционной системе для более реалистичной нагрузки на диск.
