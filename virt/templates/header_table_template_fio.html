Описание

В тесте производится оценка производительности дисковой системы с помощью утилиты fio (Flexible I/O tester).
Тестовый сценарий:
Случайное чтение/запись (random read/write) файлов размером 4 Кб.
Прямой асинхронный ввод/вывод (aio=direct), который минимизирует кэширование в операционной системе для более реалистичной нагрузки на диск.
Операции с различными уровнями глубины очереди (queue-depth), которые определяют количество операций ввода/вывода, ожидающих выполнения.
