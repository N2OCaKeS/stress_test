Описание

В тесте используется бенчмарк, который предоставляет базовый индикатор производительности Unix-подобной системы.
Тесты для многопроцессорной системы. Выполняются на ВМ.
По умолчанию выбранные тесты выполняются трижды - один раз с 4 копиями каждой тестовой программы,
запущенной одновременно, далее с 8 и 12 копиями при выделенных 8 CPU.
